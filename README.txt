Zuri POS Desktop Application
============================

The application is now available as a proper Windows installer.

INSTALLATION:
1. Double-click "Zuri POS Desktop App Setup 1.0.0.exe".
2. Follow the on-screen instructions (the installer includes a loader).
3. The installer will automatically:
   - Create a "Zuri POS" shortcut on your Desktop.
   - Add the app to your Start Menu.
   - Launch the application once installation is complete.

PORTABLE VERSION:
- If you don't want to install, you can also use "Zuri POS Desktop App 1.0.0.exe". This version runs immediately without any installation.

OFFLINE FEATURES:
- Standalone SQLite database (Offline-first)
- Inventory Management
- Sales Tracking
- Local Barcode Printing
- Cashier Management

Note: All data is stored locally on your machine.
